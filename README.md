### 🏗️ Sobre mim

- Engenheiro civil (UFV-CRP, 2018) e tecnólogo em Ciência de Dados (Estácio, 2024)
- Trabalho com obra e uso programação para tirar planilha, papel e retrabalho do caminho: controle de produção, medições, levantamentos e relatórios
- Fundador da **[WiApps](https://wiapps.com.br/)**, onde publico apps Android, jogos e ferramentas web
- Gosto de soluções simples, que funcionam no celular, até sem internet
